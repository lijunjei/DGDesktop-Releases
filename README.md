# DG桌面（DGDesktop）

DG桌面是一款 Windows 桌面整理与个性化工具，提供桌面分区、程序坞、小组件和顶部菜单。

**本仓库仅用于软件发布、下载与使用说明，不提供 DG桌面源码。**

## 下载

前往 [版本下载页面](https://github.com/lijunjei/DGDesktop-Releases/releases) 下载 Release 附件中的 Windows x64 压缩包。

请选择 `DGDesktop-…-win-x64-….zip`，不要下载 GitHub 自动生成的 `Source code` 压缩包；后者只包含本仓库的说明文档。

## 启动方法

1. 将压缩包完整解压到固定的本地文件夹。
2. 打开 `app` 文件夹，运行 **DG桌面.exe**。
3. 保留 `app` 内的辅助程序、DLL、字体、资源和 `vlc` 子目录，不要只复制主 EXE。
4. 启用开机启动或安装搜索索引服务时，按需同意 Windows 管理员授权。

## 主要功能

- 桌面图标整理、分页和桌面分区。
- 程序坞、窗口操作与顶部菜单。
- 内置文件浏览和搜索、Chrome / Edge 书签读取。
- 日历、待办、天气、音乐、歌词、灵动岛与音频可视化。
- 图片与视频壁纸，以及纯色、毛玻璃、液态玻璃等外观。

各功能需要满足对应系统和软件条件，详见 [使用条件与兼容性说明](COMPATIBILITY.md)。

## 兼容性摘要

- 当前包为 **Windows x64** 版本；建议使用 Windows 11 和单屏环境。
- 当前实际验证环境为 **Windows 11 23H2**，其他系统版本和复杂多屏组合尚未全面验证。
- **外部播放器音频可视化**对普通桌面系统的理论最低要求是 Windows 11 21H2。Windows 10 仍可按兼容性说明尝试其他功能。
- 本地音乐依赖 Windows Media Player 旧版组件及系统解码能力；当前不接入浏览器网页媒体会话。
- 天气及在线歌词需要联网；自动读取书签目前支持标准配置目录下的 Chrome、Edge。
- 高速索引搜索面向本地固定 NTFS 磁盘。
- 随包提供 VC++ x64 运行库及视频壁纸所用 VLC，无需另行安装这两项。Windows 自身组件仍须完整。
